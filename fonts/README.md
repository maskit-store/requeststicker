# Font pengganti untuk nomor batch & expired

- `FreeMono.ttf`, `FreeMonoBold.ttf` — GNU FreeFont (GPLv3 dengan *font embedding exception*), bebas disematkan di PDF. Bentuknya mirip Courier New.
- Agar hasil **identik 100%** dengan desain, upload Courier New dari Windows lewat menu **Generator Batch & Exp → Font pengganti**
  (`C:\Windows\Fonts\courbd.ttf` = Bold, `C:\Windows\Fonts\cour.ttf` = Regular), atau salin manual ke folder ini dengan nama `courbd.ttf` / `cour.ttf`.
  File Courier New tidak disertakan di repo karena lisensinya milik Microsoft.
